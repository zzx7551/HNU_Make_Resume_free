# 简历制作 1.0

一个本地运行的**简历编辑器**，界面与导出效果仿照常见的在线简历模板（左侧编辑 + 右侧 A4 实时预览），
填完内容后可一键导出 **PDF（矢量文字，清晰可打印）** 和 **PNG 长图（多页自动合并成一整张）**。

> 全部数据保存在本机 `data/` 目录，不联网、不上传，随时随地可用。

---

## 一、快速开始

> 首次打开会得到一份**示例简历**（张三 / 某某大学 / 某某科技有限公司…），
> 版式、模块结构、条目栏位都与参考模板一致，直接在示例文字上改成自己的内容即可。
> 示例头像是一张灰色占位图，点「上传图片」换成自己的照片，或点「移除」不显示头像。

1. 双击项目根目录下的 **`启动.bat`**
2. 程序会自动打开浏览器访问 <http://127.0.0.1:8765>
3. 关闭那个黑色命令行窗口即退出程序

首次启动会自动检查依赖（fastapi / uvicorn / websocket-client / pillow），
如果缺失会调用 pip 自动安装。也可以手动安装：

```bat
"C:\Users\Admin\.conda\envs\python3.12\python.exe" -m pip install -r requirements.txt
```

手动启动（等价于双击 bat）：

```bat
cd /d "D:\zzx_project\Python_Project\简历制作1.0"
"C:\Users\Admin\.conda\envs\python3.12\python.exe" run.py
```

## 二、功能说明

### 1. 左侧「基本信息」
- **姓名**、**头像**、**信息项**
  - 头像：点「上传图片」或直接点预览里的头像框 → 选择图片 → 弹出**可视化裁剪框**（拖动选框移动、拖四角/四边缩放、可锁定 117:112 比例，也可点「整张图片」）→ 确定后**只把框内区域裁好上传**（按头像尺寸 2 倍图输出，清晰不糊）。支持「移除 / 显示隐藏」，头像尺寸可在「版式样式」里调。
- **信息项**：手机、邮箱、性别、学历、户籍、求职意向…… 可任意 **添加 / 删除 / 上下移动 / 勾选隐藏**
  （与模板一致：勾选状态决定是否出现在简历上）

### 2. 左侧「模块内容」
> 左右拖动面板右侧的**分栏条**可以调整编辑区宽度（双击分栏条复位），宽度会被记住。
- 模块自带标题 + 一条长横线 + 内容，可 **添加模块 / 删除模块 / 复制模块 / 上下移动 / 拖拽 ⠿ 排序 / 隐藏**
- 每个模块内的内容块支持 4 种类型：
  | 类型 | 说明 |
  | --- | --- |
  | **经历条目** | 一行四栏：时间 ｜ 名称 ｜ 中间栏（如“本科”）｜ 右侧（如“后端开发”）；下面可挂任意条内容。**名称 / 中间栏 / 右侧加粗，时间常规**（与参考模板一致） |
  | **文本** | “标签：内容”整行，标签可留空（如：项目描述、工作内容：） |
  | **列表项** | 自动编号 1. 2. 3. / 加号 + / 圆点 • / 短横 - / 无符号 |
  | **空行** | 用于分隔或调整间距 |
- **日期选择**：经历条目点「日期」按钮，用两个月份选择器自动生成 `2022.09-2026.06`，勾选“至今”即为 `2022.09-至今`
- 条目名称对齐方式可在「版式样式」里切换 **左对齐（与原模板一致）/ 居中**

### 3. 右侧预览
- **所见即所得**：直接点击预览里的任意文字即可就地修改（回车确认）
- 顶部可缩放（−/＋/适配），可开关**分页线**，实时显示「共 N 页」
- 预览外观 = 导出的 PDF / 图片外观（同一套 HTML+CSS 渲染）

### 4. 导出
| 按钮 | 说明 |
| --- | --- |
| **导出 PDF** | A4 分页、矢量文字（缩放不糊）、可打印，条目不会被拦腰截断 |
| **导出图片** | 整篇渲染成 **一张长图**（多页自动合并），可选 1x / 2x（推荐）/ 3x 清晰度 |
| **HTML** | 导出单文件 HTML，任何浏览器打开都能看/打印 |
| **打印** | 调用浏览器打印（Ctrl+P 同效） |
| **备份 / 导入** | 导出当前简历为 JSON；从 JSON 恢复（相当于另存为副本） |

导出文件保存在 `exports/` 目录，同时浏览器会自动下载一份。

### 5. 多份简历
顶栏下拉框可切换简历，「新建 / 重命名 / 复制 / 删除」管理多份简历（例如：Java 岗、算法岗各一份）。
新建默认给一份**带示例内容的模板**；按住 **Alt 点击「新建」** 则给一份全空白模板。
所有修改会自动保存（右上角显示“已保存 / 未保存…”），也可以 Ctrl+S 手动保存。

### 6. 快捷键
| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + S` | 保存 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + P` | 打印 |
| 裁剪框内 `Enter` / `Esc` | 确定上传 / 取消 |
| 预览内 `Enter` | 结束当前文字编辑 |

## 四、版式参数（与原模板的对应关系）

模板按参考成品图逐项标定，主要参数（可在「版式样式」里实时调整）：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 页面 | A4（794px 宽） | 打印/PDF 为标准 A4 |
| 页边距 | 左右 52px，上下 27px | 与参考图 83/1280 的比例一致 |
| 正文字号 / 行高 | 13.5px / 21px | 参考图行距 33.5px ÷ 1.6 |
| 姓名 | 28px 加粗 | |
| 模块标题 | 17px 加粗 + 1px #333 分隔线 | 标题相对分隔线内缩 4px |
| 信息行 | 14px | 标签 + 全角冒号 + 值，项间距 20px |
| 经历条目 | 时间 194px ｜名称自适应｜中间栏 117px｜右侧 172px | 名称过长会像原模板一样溢出到中间栏 |
| 条目字重 | 名称 / 中间栏 / 右侧 = 700 加粗 | 时间与正文为常规字重 |
| 头像 | 117 × 112px | 距右边界 20px；未上传头像时不出现在导出结果中 |
| 条目字重 | 名称 / 中间栏 / 右侧 = 加粗 | 与参考图墨迹密度一致（正文常规、标题加粗） |

> 说明：原站导出图宽 1280px（≈1.6 倍缩放），本程序导出默认 2 倍（1588px 宽），
> 清晰度更高；如需与参考图完全同尺寸，可选「导出图片 → 标准 1x」附近的倍率。

## 五、常见问题

**1. 导出失败 / 提示找不到浏览器**
导出使用本机已安装的 Edge 或 Chrome（无头模式）渲染，需保证二者之一存在。
如装在特殊路径，可设置环境变量 `RESUME_BROWSER` 指向浏览器 exe。

**2. 端口被占用**
启动时若 8765 被占用会自动改用 8766 / 8767 / 8768 / 8899。

**3. 第一次导出比较慢**
首次导出需要启动无头浏览器进程（约 1~2 秒），之后会复用，导出通常在 1~2 秒内完成。

**4. 字体**
默认使用微软雅黑；可在「版式样式 → 字体」切换宋体 / 黑体 / 等线 / 楷体等（需系统已安装）。
PDF 会内嵌字体，换电脑打开也不会变形。

**5. 内容丢失？**
每次保存前都会在 `data/backups/` 留一份备份；浏览器也会缓存草稿。
误删简历时可以从备份 JSON 中恢复。

## 六、技术要点

- **预览与导出同源**：编辑器预览与导出页共用 `resume.css` + `render.js`，
  导出时由无头浏览器加载同一个页面（`/export/view/{id}`）后截图 / 打印，
  因此“导出结果 = 预览效果”，不会出现排版漂移。
- **PNG 长图**：通过 CDP `Page.captureScreenshot`（captureBeyondViewport）一次性截取整篇，
  多页内容天然合并为一张，不会出现分页缝隙。
- **PDF**：通过 CDP `Page.printToPDF` + `@page` 规则输出 A4 矢量 PDF，
  并对经历条目设置 `break-inside: avoid`，避免条目被分页截断。
- 后端零数据库：所有数据为 UTF-8 JSON 文件，随时可备份、迁移、手工改。
